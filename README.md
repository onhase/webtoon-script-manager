# 🎨 Webtoon Script Manager
웹툰 작가를 위한 효율적인 글콘티/글콘티(글콘티 메이커) 작성 도구입니다.

## 💡 주요 기능
* **⚡️ 저장 시스템**
    * `Ctrl + S`: 현재 작업 파일 즉시 덮어쓰기 저장
    * `Ctrl + Shift + S`: 다른 이름으로 저장 (새 경로 지정)
* **⌨️ 키보드 중심의 빠른 작업**
    * `Shift + Enter`: 현재 컷 아래에 새 컷 추가
    * `Ctrl + 방향키`: 컷/대사 칸 사이 자유로운 순간 이동
* **✂️ 컷 & 블록 관리**
    * 컷 넘버 클릭 시: 컷 이동(드래그), 삭제, 복사, 추가 가능
    * 컷 넘버 클릭 시: 스크롤 연출용 **[여백 블록]** 및 대사 전용 **[대사만 블록]** 추가 가능
* **📝 스마트 메모 & 참고**
    * 가로 모드에서는 우측, 세로 모드에서는 상단에 메모를 배치할 수 있습니다.
    * 메모 영역은 상황에 따라 접거나 펼칠 수 있어 작업 공간 확보에 용이합니다.
* **📋 원클릭 대사 복사**
    * 대사칸 상단의 헤더를 클릭하면 해당 대사가 즉시 클립보드에 복사되어 원고에 붙여넣기 할 수 있습니다.
* **🎨 맞춤형 작업 환경**
    * 우측 상단 ⚙️(설정)을 통해 **테마 컬러, 폰트 종류, 폰트 크기**를 실시간으로 조절하여 나만의 작업 환경을 만드세요.
* **📂 에피소드 관리**
    * 상단 폴더 및 에피소드 탭을 통해 여러 화를 하나의 파일 안에서 체계적으로 관리하세요.
* **📱 반응형 인터페이스**
    * 브라우저 창의 비율에 따라 가로/세로 모드로 자동 전환되며, 모바일 환경에서도 최적의 글콘티 환경을 제공합니다.
