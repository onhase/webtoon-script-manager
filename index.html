📖 Webtoon Script Manager 사용법

  • Ctrl + S : 저장
    Ctrl + Shift + S : 다른 이름으로 저장
  • Shift + Enter : 아래에 새 컷 추가
  • Ctrl + 방향키 : 방향으로 셀 이동
  • 컷 넘버를 클릭하여 컷을 이동(드래그), 삭제, 추가할 수 있습니다.
  • 컷 넘버를 클릭하여 스크롤 연출용 <여백>이나 <대사만> 블럭을 추가할 수 있습니다.
  • 가로 모드 우측, 세로 모드 상단에 참고 메모를 넣을 수 있습니다.
  • 창의 가로세로 비율에 따라 가로 모드, 세로 모드로 자동 변환됩니다. 가로 모드에서는 참고를 닫을 수 있습니다.
  • 대사칸 상단(대사 N)을 클릭하면 대사가 바로 복사되어 원고에 편하게 붙여넣기 할 수 있습니다.
  • 우측 상단의 톱니바퀴(⚙️)를 눌러 테마 색상, 폰트, 글자 크기를 조절할 수 있습니다.
  • 상단의 에피소드 폴더와 시트(탭)를 이용하여 여러 화를 한 번에 관리해 보세요.
